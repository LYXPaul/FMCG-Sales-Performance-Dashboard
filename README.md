# FMCG Sales Performance Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard developed to analyse FMCG sales performance from 2021 to 2025. The analysis transforms transactional sales data and product information into meaningful business insights related to revenue, profitability, product performance, sales channels and margins.

The dashboard was designed to support data-driven decision-making by allowing users to explore business performance across different years, products and categories.

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and business calculations
* **Data Modelling** – Integration of transactional and product data
* **Microsoft Excel** – Source data management

## 🎯 Business Objectives

The project aims to:

* Evaluate overall sales and profitability performance from 2021–2025
* Identify popular and profitable products
* Compare product performance across different price tiers
* Analyse profit margins across products and categories
* Examine sales performance and trends over time
* Provide actionable insights to support business decision-making

## 🧹 Data Preparation

The dataset was prepared using Power Query before dashboard development. Key preparation activities included:

* Cleaning and standardising transactional data
* Checking and assigning appropriate data types
* Integrating sales transaction data with product master data
* Establishing relationships between tables
* Creating calculated measures using DAX
* Preparing data for interactive analysis and visualisation
